# Practical Science & Analytics Lab

Practical Science & Analytics Lab は、統計学・データサイエンス・機械学習・因果推論などを、
実務で活用できる形で分かりやすく解説する書籍シリーズを制作しています。

本リポジトリでは以下を公開します。

- 書籍ごとのサポートページ
- 演習問題回答
- 正誤表
- サンプルコード
- 追加資料

## Books

  2. [機械学習実務基礎](./books/machine_learning/README.md)
