## 本書について

本書は、機械学習を単なるアルゴリズムの知識としてではなく、

* どのような課題に適用できるのか
* どのようにモデルを構築・評価するのか
* どのようにビジネス価値につなげるのか

という実務の流れに沿って体系的に学ぶことを目的としています。

機械学習の学習では、個々のアルゴリズムやライブラリの使い方に注目が集まりがちです。
しかし実務において重要なのは、適切な問題設定を行い、データを理解し、モデルを評価し、継続的に改善していく一連のプロセスです。

本書では、回帰や分類といった教師あり学習を中心に、特徴量設計、モデル評価、ハイパーパラメータチューニング、解釈性、ビジネスインパクト評価、本番運用までを一貫して解説します。

また、数式や理論だけでなく、「なぜその手法が必要なのか」「実務ではどのように使われるのか」を重視し、機械学習プロジェクトを自ら推進できるようになることを目指しています。
