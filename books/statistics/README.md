## 本書について

本書は、統計学を単なる数式の暗記ではなく、

* なぜその手法が必要なのか
* 実際に実務のどのような場面で使うのか
* 結果をどのように解釈するのか

を重視して解説しています。

理論と実務の橋渡しを目的とし、統計学を実際のデータ分析で活用できるようになることを目指しています。
